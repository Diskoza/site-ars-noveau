# Adam's Ars Plus Wiki

An unofficial offline wiki in Russian for the [Adam's Ars Plus](https://www.curseforge.com/minecraft/mc-mods/adams-ars-plus) mod for Minecraft 1.20.1 (an Ars Nouveau addon). A static website with no server or database.

**Versions:** Minecraft 1.20.1 · Adam's Ars Plus 5.0.3 · Ars Nouveau 4.12.7

## Contents

- Global search and a progression tree.
- 36 glyphs with Russian descriptions.
- 169 recipes.
- Full registry: 76 items, 20 blocks, 26 entities, 21 effects.
- Six armor sets, including awakened variants.
- Six structures with dimensions, biomes and heights.
- A Ten Shadows and Mahoraga section.
- Dark responsive design with an animated background.

The data (recipes, registries, names, structures) was extracted from the mod files.

## Running

Open `index.html` in a browser or run `START_SITE.bat`. The site can be hosted on any static host: GitHub Pages, Cloudflare Pages, Netlify, etc.
