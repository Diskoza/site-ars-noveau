ADAM'S ARS PLUS WIKI — первая рабочая версия
================================================

Версии:
- Minecraft: 1.20.1
- Adam's Ars Plus: 5.0.3
- Ars Nouveau: 4.12.7

КАК ОТКРЫТЬ
1. Распакуйте архив целиком.
2. Откройте index.html двойным щелчком.
3. Интернет, Node.js, npm и база данных не требуются.

КАК РАЗМЕСТИТЬ В ИНТЕРНЕТЕ
Загрузите всё содержимое папки на любой статический хостинг: Cloudflare Pages,
GitHub Pages, Netlify, обычный nginx/Apache или хостинг с файловым менеджером.
Главным файлом должен оставаться index.html.

ЧТО УЖЕ ЕСТЬ
- тёмный адаптивный дизайн и анимированный магический фон;
- глобальный поиск;
- дерево прогрессии;
- шесть worldgen-структур с измерениями, биомами и высотами;
- шесть комплектов брони, включая пробуждённые варианты;
- 36 глифов с русскими описаниями;
- раздел Ten Shadows и Махораги;
- 169 рецептов из JSON аддона;
- полный реестр 76 предметов, 20 блоков, 26 сущностей и 21 эффекта;
- оригинальные текстуры из JAR.

ДОСТОВЕРНОСТЬ
Рецепты, реестры, названия, встроенные описания, структуры, биомы и высоты
извлечены непосредственно из файлов adamsarsplus-1.20.1-5.0.3.jar и
ars_nouveau-1.20.1-4.12.7-all.jar.

Это первая рабочая версия вики. Для полного справочника «абсолютно обо всём»
следующим этапом нужно дополнять базу результатами глубокого анализа байткода:
точные характеристики мобов, формулы урона, кулдауны, лут, условия рангов
Ten Shadows, способности предметов и проверка редких механик в игре.
